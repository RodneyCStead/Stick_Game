# Stick It To Em - Card Battle Game

A turn-based stick figure card battle game built with Python and Pygame.

## Features
- Platform-based combat system with stick figure characters
- Turn-based card gameplay
- Player vs Enemy battles
- Web deployment ready with pygbag

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run the game: `python src/main.py`

## Web Deployment
1. Build for web: `pygbag src/main.py`
2. Deploy the `web_build/` folder to GitHub Pages

## Game Mechanics
- Stick figure player on the left, enemies on the right
- Cards displayed in bottom panel
- Turn-based combat system
- Click cards to activate abilities

## Art Assets
Place your stick figure art in the `assets/sprites/` folders:
- `characters/` - Player and enemy stick figures
- `cards/` - Card artwork
- `platform/` - Battle background
- `ui/` - User interface elements
